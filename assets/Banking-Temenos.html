Banking Project — Temenos

Overview: Cloud engineering and infrastructure work for the Temenos core banking platform. Responsibilities and contributions include:

  • Designed and implemented secure, highly available cloud infrastructure for Temenos deployments.
  • Integrated Temenos modules with managed databases, messaging, and external services.
  • Implemented infrastructure-as-code using Terraform and automated deployments with CI/CD pipelines.
  • Configured monitoring, logging, and alerting for core banking services to meet SLA requirements.
  • Worked on security hardening, IAM policies, network segmentation, and compliance controls.
  • Performed backup, recovery planning, and failover testing for production readiness.
  • Collaborated with application and QA teams to validate integrations and performance tuning.
